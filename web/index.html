Use desktop Chrome or Edge with Web Serial. Open this page over HTTPS to allow USB access. Użyj Chrome lub Edge na komputerze. Otwórz tę stronę przez HTTPS, aby zezwolić na USB.

Cardputer-ADV only · flashing replaces firmware and clears saved memories

help
  1. Connect the Cardputer-ADV with a data-capable USB-C cable.
  2. Close serial monitors, press install and choose USB JTAG/serial.
  3. Wait for verification. Grajek restarts by itself.

No port? Switch it off, hold G0 while reconnecting or powering on, release G0, then try again.
